The comic

About Dan

Dan Young is a Midwest stand-up working rooms the way the Midwest actually lives: family, fandom, work weeks that run long, and the kind of punchlines that only work if you’ve been in the parking lot after last call.

He’s a comic-book nerd who treats the stage like a longbox — pull a title, crack it open, see what still holds up. The act sits between observational and slightly dangerous: clean enough for a Saturday banquet if you ask, sharp enough for a late club set if you don’t.

  • Home base: Midwest circuit (Lincoln / Omaha corridor and out)
  • Lane: stand-up · hosting · features · private events
  • Voice: working-class Midwest, comic-shop brain, no TED-talk polish
  • Available: clubs, colleges, corporates, fundraisers, roast-friendly rooms

Work

Book Dan

Clubs, colleges, corporate banquets, fundraisers, private parties. Tell him the room, the runtime, and whether the set needs to stay clean.

Clubs & showcases

Feature and headline-ready sets. Hosting available. Send the room size, door split, and whether you need a tight 10, a 20, or a 45.

Private & corporate

Banquets, holiday parties, fundraisers. Clean or club — say it in the first email so the set matches the room.

Colleges & events

Midwest-friendly material, easy load-in, no diva rider. A mic, a light, and a crowd that wants to laugh is enough.

Booking inbox: booking@danyoungcomedy.com — create that address. Do not put a personal cell on this page.

What to send Dan

  • Date + city + venue type
  • Set length (10 / 20 / 45 / host)
  • Clean, dirty, or “read the room”
  • Audience size and age range
  • Fee or door deal
  • Travel if it’s outside the Lincoln–Omaha corridor
