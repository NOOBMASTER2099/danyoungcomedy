## GitHub Pages
1. Repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Custom domain: `danyoungcomedy.com` (CNAME is already in the repo)
5. At the registrar, point the domain at GitHub Pages the same way Nebraska Comics is pointed
