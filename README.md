# Dan Young Comedy

Official site template for [danyoungcomedy.com](https://danyoungcomedy.com)

Midwest stand-up. Comic-book nerd. Same GitHub setup as Nebraska Comics.

## Live files
- `index.html` — one-page site (current live homepage)
- `CNAME` — points GitHub Pages at danyoungcomedy.com
- `logo.jpg` — D.Y.C. mark
- `stage.jpg` — mic, stool, brick-wall logo
- `crop.jpg` — field / crop-circle art
